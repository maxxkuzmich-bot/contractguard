# Next Steps For You

When you get access to laptop:

1. Download latest ZIP.
2. Unzip it.
3. Run backend:
```bash
cd server
npm install
node server.js
```

4. Run frontend:
```bash
cd client
npm install
npm run dev
```

5. Test sample contract.
6. Add OpenAI API key later.
7. Deploy online.

Current MVP is ready enough for local testing and early demo.
